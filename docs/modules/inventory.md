# 物资管理详细设计

从桌面侧栏进入「物资」，顶部并列「物品」「食品」「药品」。搜索和登记都在当前分类内进行，返回时保留筛选和选中行。三类共用位置、入库和数量记录，各自有独立的登记表、详情页和常用动作。

| 分类入口 | 家人想解决的问题 | 默认工作区 |
| --- | --- | --- |
| [物品管理](inventory/items.md) | 家里有哪些东西、放在哪、借给了谁？ | 家庭物品清单，按名称或位置查找 |
| [食品管理](inventory/food.md) | 哪些先吃、含哪些配料、这一份有多少热量、这次买得贵吗？ | 食品库存，可切到「优先吃」，从列表选择两款对比标签与价格 |
| [药品管理与用药计划](inventory/medicine.md) | 药箱里是哪种规格、何时到期、今天的用药有没有记录？ | 家庭药箱，可切到「用药计划」查看今日待记录项 |

## 桌面操作

在 1440 × 900 的工作区，标题行放分类主操作，下面是搜索、常用筛选和列表。点击行名可在右侧查看位置、数量、登记人和该类详情。1280 × 720 窗口优先保留名称、位置、数量与当前动作，次要字段收进详情。食品对比与用药计划占完整工作区。每个分类记住上次的筛选，从首页提醒进入时则带入本次提醒的条件。

初次整理时，可以只录「一把电钻」「冰箱里两杯酸奶」或药盒上的药名、剂型和规格。可选字段留空显示「未录」，家庭成员有标签或小票在手时再补。库存登记、食品标签补录、建立用药计划均可独立完成。

## 记录归属与家庭库存

| 记录 | 保存的事实 | 写入规则 |
| --- | --- | --- |
| 品目资料 | 名称、类别、库存单位及本类特征，例如食品标签、药品剂型 | 家人可复用同一品目。建档者维护资料，其他成员可在该品目新增自己的入库或使用记录 |
| 入库与批次 | 谁在何时登记、品目、位置、数量、来源。食品和药品按包装、日期分批 | 入库人拥有本次记录。采购带入的品目与行项目可回查，重复确认同一次收货只入库一次 |
| 库存变动 | 来源批次或位置、动作、数量、时间、经手人。移动记录来源和去向 | 每个动作生成当前成员自己的流水。家庭共享库存按有效流水汇总，取用他人登记的物资会留下本人的取用记录 |
| 食用、用药与计划 | 本人实际食用或用药的事实、关联批次及采取的库存动作。计划定义未来安排 | 本人创建并维护，家人登录后可读。提醒只是待处理事项，只有明确确认实物变化才影响数量 |

服务端从当前会话确定所有者，对修改、撤回、附件更换逐条检查归属。创建自己的流水不能更改他人的原记录或撤销他人的动作。更正本人流水时保留原值，展示对余额的影响。如果另一笔后续记录已用去库存，先提示剩余可更正数量。品目或标签已有历史引用时归档保留，历史详情仍能打开。[账号与成员约定](accounts.md)

## 单位与数量核对

- **入库。** 品目选一个基本库存单位。按箱购买可在收货行确认「2 箱 × 每箱 6 盒 = 12 盒」。整数件数与可分量的克、毫升分别校验。已有流水沿用原单位，换包装时保存当次换算。
- **在家与可用。** 按位置、批次汇总实物。借出量保留在家庭拥有量中。食品和药品可分别设定提前几天提醒。有明确到期日的批次到期当天显示「今日到期」，次日进入「待清理」。过期或日期待核的余量单列，实际清理后才从实物库存扣除。新鲜食材可按入库日和优先食用日管理。
- **盘点与退回。** 按位置及批次填实数，确认前展示「账面 5、实有 4、差额 −1」。采购退货按实际退回数量记到原批次。并发取最后一件时重新核对余量，后提交者看到最新数量。重试、更正和撤回都不能让库存变为负数。
- **补货与采购。** 低于或等于补货线时显示家庭可用量和剩余待买量。可查看已有待购项，或在同页添加本人的需求。本人的采购收货可关联位置、批次和价格。库存里的价格信息沿用采购记录，记账由财务流水承接。[采购与收货](procurement.md)

## 跨分类验收

| 场景 | 预期结果 |
| --- | --- |
| 从三个入口分别新增，逐项检查必填内容 | 电钻没有保质期字段，酸奶可先不填热量，药品须区分剂型和规格。三种都能先登记再补资料 |
| 甲登记一批物资，乙登录后取用一件并尝试编辑甲的原记录 | 乙的取用流水可以保存，家庭余量只减一件。甲的原入库数量及登记人保留，服务端拒绝乙改写或撤回甲的记录 |
| 从采购收货后重试，再打开库存详情 | 只有一组入库变动，可回查该次收货。食品可分别核对单价和标签，只有一份付款来源 |
| 两人同时取最后一件 | 一个动作成功，另一个看到最新余量，可以修正输入，没有负库存 |

## 当前实现进度

| 切片 | 已可在网站操作 | 后续设计 |
| --- | --- | --- |
| 家庭库存 | 分类登记、复用品目追加入库、包装换算、位置与批次查询、移动、盘点、处置、低库存筛选、本人流水撤回 | 采购收货关联、补货需求、附件和归档 |
| 物品 | 按别名、位置或标记查找，借出与部分归还，按批次送修、取回和领用 | 保修凭证、预计归还日与资产卡 |
| 食品 | 配料与过敏原原文、包装日期、新鲜食材登记、部分开封、按批次优先食用清单 | 标签版本、营养与买价对比、分食及个人摄入记录 |
| 药品 | 分剂型和规格登记，按日或按月保存有效期，入库人可补核包装日期，按批次领用 | 说明书附件、本人用药计划、提醒与实际用药记录 |

库存共用 `inventory_products` 品目表和 `inventory_movements` 流水表。登记与库存动作在一个事务内提交，同一品目的写入先锁定品目再核对余额。客户端重试同一请求时复用请求标识。借出和送修只转移实物状态，领用和处置减少拥有量。撤回追加关联原流水的逆向记录。
