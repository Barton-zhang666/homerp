# 药品管理与用药计划

药品页设「家庭药箱」和「用药计划」。家人可以在药箱里核对手上这盒药的名称、剂型、规格和有效期。需要提醒时，本人把已有医嘱或说明录入计划。药盒上的用法用量、个人计划用量、某一次实际用量分别保存，查看记录时可以追溯各自依据。

## 药箱登记与查询

| 层次 | 要记的内容 | 桌面上的用途 |
| --- | --- | --- |
| 快速建档 | 药名、剂型、规格、库存数量和单位。剂型如片剂、胶囊、口服液、外用制剂，规格保留包装原文 | 同名不同剂型或规格分行显示。缺少关键信息可保存待核对草稿，补齐后再用于计划 |
| 药品资料 | 通用名、商品名、有效成分、生产厂家、包装数量与换算关系。可附盒面、说明书照片及版次 | 按通用名、商品名、成分查找。列表同时显示剂型与规格，避免只看商品名选错包装 |
| 说明与标签 | 适应症、用法用量、给药途径、注意事项、禁忌及贮藏条件，按所持说明书录入。可加「外用」「旅行药箱」等标签，处方／非处方属性按包装标识记录 | 支持按适应症原文或标签检索，结果保留说明来源并可直接打开原图。说明书的通用描述独立于本人的计划 |
| 实物批次 | 批号、包装标示有效期及日期精度、存放位置、余量、开封日。包装有明确启用后期限时可录原文和确认的截止日 | 同一药品分批、分位置看余量。按「临期」「本月需核对」「已过期」「日期待补」「库存不足」筛选 |

主表一行是一种具体剂型和规格，显示药名、规格、剂型、可用量、最近有效期及位置。右侧面板顶部同时显示盒面与规格，下面分「说明」「库存批次」「相关计划」。登记完药箱即可退出，适应症、标签、附件和计划均可稍后补充。

批次有精确日期时按日提醒。只印有年月时按原样保存，提醒显示「本月到期，核对包装」，过了标示月份转为已过期。当前月内需核对日界限的批次和日期不明的批次单列。启用后另有明确截止日时，对已开封包装按两个已确认截止日中较早者提醒。已过期批次保留清理入口。用药登记自动选批只选剂型、规格一致且有效期明确可用的实物。

## 建立本人的用药计划

1. 在药品详情点「建用药计划」，或从计划页点「新增」再选药品。表单顶部固定显示本人、药名、剂型和规格，可链接本人的相关就诊记录。药箱说明与来源可在右侧对照。
2. 按本人已有的用药说明填写单次用量、单位、途径、频次、起始日和可选结束日，注明来源。可选每日指定时间、每周指定日、按既有说明设置的间隔，或「按需记录」。条件、疗程和备注可保留原文。按需记录只提供登记入口。
3. 保存前预览未来几次提醒的日期、时间和显示用量，核对后启用。剂型、规格、适应症、库存不足或一次漏记均不会触发系统推算、替换或调整用量。单位换算仅用于核算实物消耗。
4. 计划页上方按日期显示「今日待记录」，下方列进行中、暂停和已结束的计划，可按成员查看。本人可调整未来安排、暂停、恢复或结束。更改保留生效日期和历史版本，既往记录继续显示当时的用量与说明。

## 从提醒到实际记录

| 家人的操作 | 日程及用药记录 | 库存结果 |
| --- | --- | --- |
| 打开或延后提醒 | 仍待记录，只变更本次提示时间。到点仍未处理显示「未记录」 | 无库存变动 |
| 选择「已用药」 | 本人核对实际时间、实际用量、单位，可注明与计划不同的原因。补记可填实际发生时间 | 确认关联批次和可换算的实物量后一次扣减。部分已提前取出时可关联领用流水，已扣部分不再扣 |
| 选择「本次跳过」 | 标记本次已处理，可记原因。下次按原计划显示 | 无库存变动 |
| 只从药箱取出备用 | 记一次领用及数量，后续可关联实际记录 | 领用时扣药箱余量，实际用药时间留待本人记录 |
| 无家庭库存或用量单位无法换算 | 允许本人记录实际用药，标明外部来源或「库存待核对」 | 不从相似药品或其他规格代扣，补齐数量和批次后可对同一记录确认一次 |

例如药箱按盒购入、按片管理时，收货按该包装确认每盒片数。计划使用的单位与库存单位之间若缺少明确换算关系，保留原单位。登记人可按实际取用确认库存数量，软件不会依据质量单位自行推算片数或拆分剂量。

计划在家庭日历中可见，提醒发送给计划本人。本人从日历处理时打开同一次用药登记。日程按钮、计划页操作和重复提交共同引用这一次发生记录。更正本人误记时预览将恢复或扣减的库存。此前只关联已领用数量时只修正关联量。提前领用的总量可分次关联，用尽后不再供下次抵扣。

对频次、用量均固定且库存可换算的计划，可展示在指定日期前「预计所需、当前有效可用、尚缺」的量，点「加待购」由本人确认需求。同一药品的多份固定计划共享实物余量，按日期汇总需求，排除到对应日期已失效的批次。按需计划只显示现存量。补货或缺货只改变物资信息。

## 桌面验收

| 家庭操作 | 预期结果 |
| --- | --- |
| 搜索同通用名的片剂和口服液，按「外用」标签另作筛选 | 前一次结果分行显示剂型、规格与盒面，后一次结果按已录标签匹配，均可打开原始说明 |
| 同一规格有一批已过期、一批有效，另有只有年月且本月到期的一批 | 三批均可查。自动选批只用明确有效的一批，清理过期实物不改其他批次 |
| 本人从周历确认一条计划，从药箱再次打开同一提醒 | 只见一条实际记录和一次扣减。另一位登录成员可读，无法代为确认或修改用量 |
| 先领用再分次记录实际用药，其中一次跳过 | 领用只扣一次，已用数量逐次与领用量核对，跳过不占量。未处理的事项仍显示未记录 |
| 改下一周的计划并暂停，之后恢复 | 原记录和原说明可以回看，暂停期间不产生新提醒，恢复只预排生效后的时段 |
| 已实际用药但没有可核对的库存单位 | 可以留存实际时间和原始用量，库存不变，后续补核一次即可 |
