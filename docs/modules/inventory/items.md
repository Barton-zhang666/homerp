# 物品管理

物品页收录家具、家电、工具、衣物、证件收纳和日用耗材。第一次整理以「家里有什么」为起点。录入「电钻」就能在清单看到 1 件，可马上选「储物间」，也可稍后补位置。登记表和详情均无保质期、生产日期或临期提醒。

## 记录内容

| 何时填 | 内容 | 用途 |
| --- | --- | --- |
| 快速登记 | 名称必填，数量默认 1，单位默认件，位置默认未指定 | 能按名称查找、按位置汇总。连续录入时可沿用位置，方便一次整理一个柜子 |
| 找东西时有帮助 | 分类、用途标签、别名、照片、具体位置，例如「书房／第二层抽屉」 | 搜「充电头」可命中别名为充电头的电源适配器，查看照片核对实物 |
| 区分同款时 | 品牌、型号、颜色、规格。需逐件辨认时可加单件名称、序列号或标记照片 | 同型号三件可合并看数量，其中一件送修或借出时仍能定位到具体实物 |
| 按用途选填 | 耐用品可填购入日、凭证、保修截止日或说明书。耗材可设常备量与补货线 | 售后时找到凭证，快用完时加入待购。保修信息只在耐用品详情按需展开 |

## 页面与常用动作

物品清单默认列「名称、在家可用、位置、状态」。顶部可按位置、分类筛选，常用筛选为「借出中」「库存不足」。点击某个位置可以列出「这个柜子里有哪些东西」。详情先显示所在位置及各处数量，再列借用、使用和移动历史。对普通物品只显示登记、移动与盘点，选「常用耗材」或「按件跟踪」后展开对应动作。

| 动作 | 当场需要输入 | 结果 |
| --- | --- | --- |
| 找到并移动 | 目标位置，数量默认 1 | 原位置减少、目标位置增加，家庭拥有量相同 |
| 借出与归还 | 借用人、数量，可选预计归还日。归还时填实际数量和放回位置 | 借出明细显示「谁借了几件」，允许部分归还。归还人可追加自己的归还记录，历史保留原借用记录 |
| 使用耗材 | 用掉多少，默认 1 个库存单位 | 扣减所在位置的可用量，达到补货线时可直接加待购 |
| 送修与取回 | 选择具体实物、送修日期，可补维修点或凭证 | 送修期间从可用量移出。取回后选位置恢复可用 |
| 处置与盘点 | 报废、赠出时确认件数。盘点时填当前位置实数 | 处置减少家庭拥有量。数量归零仍保留历史，可按需归档品目 |

同一把电钻在同一时间只能处于在家可用、借出、送修、已处置中的一种状态。部分借还或送修按受影响的件数更新，待归还量和待取回量分别核对。同款消耗品按数量处理，无需逐卷登记序列号。电动车等已建资产卡的物品可关联财务查看估值，物品清单只统计实物件数。

## 桌面验收

| 家庭操作 | 预期结果 |
| --- | --- |
| 在书房连续登记台灯和订书机，只填名称并沿用位置 | 物品清单出现两行各 1 件，按书房筛选均能找到，全程无需日期 |
| 2 把电钻借出 1 把，之后放回另一处 | 借出时显示拥有 2、在家可用 1。归还后可用 2，能查到两个位置和借用历史 |
| 3 包纸巾用掉 1 包，补货线为 2 包 | 可用量为 2，行内可见待买量和补货入口，清单不会因查看提醒而自行增加 |
| 同款两件设备只送修其中有序列号的一件 | 另一件仍可借用，送修件显示凭证及状态，取回时可直接更新存放位置 |
