# 单机版用户模块
本设计采用一份本机名册。所有成员自行注册并拥有同等权限。成员的业务记录对已登录家人共享，所有者可以修改自己的内容。登录邮箱、密码凭据和会话不属于共享资料。该约定优先于旧设计中的管理员、代建账号和邀请注册流程。

## 执行步骤与验收
1. 建立成员账号与会话表。邮箱归一化后唯一，注册时原子创建本人的档案和会话。
2. 提供自行注册、登录、当前用户和退出接口。会话使用随机令牌，数据库只存摘要，浏览器使用 HttpOnly Cookie。
3. 提供共享名册和个人设置。修改入口以当前会话确定所有者。更改密码或停用须验证当前密码并撤销全部会话。恢复须由本人在登录页明确操作。
4. 生成 OpenAPI 类型，实现注册登录页、可搜索的名册和个人设置。页面刷新后重新读取会话。
5. 测试重复注册、匿名访问、资料归属、撤销与恢复，执行 MySQL 迁移并验证契约及前端构建。

停用保留成员档案和称呼，仍供其他登录成员查询。会话有效期为七天。未来的业务记录应保存所有者成员 ID，在服务端检查修改权。
