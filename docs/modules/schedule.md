# 日程与长期计划详细设计

家人在一周视图里安排接送、家务和约会，也能把「春节前整理全屋」这类目标拆成步骤。已排期的步骤直接出现在日历，家人只需维护一份完成状态。

## 桌面日历与计划页

| 页面 | 工作区布局 | 常用动作 |
| --- | --- | --- |
| 日历 | 顶部放「今天」、前后翻页、日期范围、成员筛选和「新建日程」。默认周视图，每日一列，全天事项在上，定时事项在时间轴上 | 点击空白时段带入日期和起始时间，点击事项打开右侧详情，可改期、完成或取消 |
| 月历与议程 | 在同一工具栏切换视图，保留已选日期和成员。月历显示事项标题与每日总数，议程按日期逐行列出时间、事项和负责人 | 月历中点某日的「另有 3 项」查看当日全部安排。议程可筛待办或逾期任务 |
| 长期计划 | 左边列进行中、暂停和已完成的计划，选中后右边展示目标、负责人、截止日期和步骤清单 | 在行内添加步骤、勾选完成或指定日期。计划详情可直接打开某一步的日历安排 |

用户可切换「我的安排」与「所有可见安排」，再按成员筛选。多人一同参加的约会只占一项，重叠的定时安排并列展示。冲突提示给出当前成员有权看到的事项，由成员决定是否保留两个安排。

## 新建与处理日程

1. 在日期格或页头点「新建日程」，填标题和日期即可保存。点时间格时带入所选时段，点日期时默认全天。可选结束时间或结束日期，预览跨天范围。
2. 用「需要勾选完成」区分任务与普通约会。任务默认由自己负责，可指定家庭成员。约会可添加多名参与人。共享范围可选本人、指定成员或全家，保存前展示谁能看到。
3. 展开「重复与提醒」可设每天、每周几、每月、每年或自定间隔，选填截止日期。提醒支持当天或提前指定时间，在站内提醒列表展示。可延后一次或关闭后续提醒。使用家庭时区解释日期、月末和提醒时间。
4. 任务完成后仍可在历史中查看，误勾可重新打开。逾期未完成任务留在待办，普通约会在结束后进入历史。取消本次会移除其待处理提醒，已完成的缴费任务可从详情另行确认实际付款。

## 重复安排与单次例外

保存前预览接下来三次发生日期。每月 31 日的安排在短月落到该月最后一天，下一月继续按原规则推算。每周二、四倒垃圾时，可对某个周二选择「仅这次」改到周三或跳过。「这次及以后」从选定日期起套用新规则，已完成记录与过去的单次改动保留。若会影响未来已单独调整的事项，保存前列出影响范围，让成员保留或重新安排。

同一系列的每次发生独立记录完成与提醒状态。修改周二的标题、参与人或提醒，只在成员选定的范围内生效。查看已改期的一次会显示原日期和当前日期，方便其他参与人核对。

## 长期计划与关联事项

建计划先填目标名称，截止日期和协作成员按需补。步骤有名称、可选负责人、可选日期和完成状态。未排期步骤只在计划内展示，排期后日程和步骤指向同一项。清除日期会移出日历，保留步骤内容。

有步骤时显示「已完成 2 / 5」，全部勾选后可结束计划。没有步骤的目标可手动完成。暂停时保留步骤和进度，暂缓未来步骤的提醒，恢复时先列出逾期步骤供成员改期。步骤沿用计划可见范围。

从健康记录建立的复诊安排默认沿用原授权，日程只显示标题、时间和获准参与人，查看报告返回成员档案。取消复诊会释放日历时段，原就诊记录保留。缴费任务只记录行动，确认金额及账户后才在财务留下流水。

药品模块可将已启用的用药计划显示在周历和今日议程中。点击某次提醒会打开该次用药记录，由本人确认已用、跳过或延后。用量及库存处理见[药品与用药计划](inventory/medicine.md)。

## 桌面验收

| 操作 | 可核对的结果 |
| --- | --- |
| 在周历将本周二倒垃圾改到周三，选择「仅这次」 | 周三出现一项，原周二时段清空，周四及下周仍按原规则 |
| 在计划中给「整理厨房」排周六，再在周历完成 | 计划完成数从 0 / 3 变为 1 / 3，在任一处重新打开都会恢复为 0 / 3 |
| 查看月末缴费并将一次提醒延后 | 日期预览覆盖短月，只有所选那一次的提醒时间改变 |
| 照护人从就诊记录建复诊安排，另一位普通成员查看全家月历 | 照护人可见复诊，未获授权的成员看不到标题、提醒和该事项的计数 |
