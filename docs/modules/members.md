# 成员与健康档案详细设计

同一份成员名册供日程选负责人、采购记经手人和健康档案确定归属。家里没有登录账号的孩子或老人也可以先建资料，之后绑定账号仍沿用原档案。

## 桌面名册与个人资料

进入成员页，左侧显示可搜索的名册，右侧展示选中成员的资料。名册行使用称呼、头像或姓名首字和家庭关系，同名时用关系或备注区分。右侧标题始终显示当前成员称呼，避免连续录入时记错人。

| 分页 | 工作区内容 | 可执行的操作 |
| --- | --- | --- |
| 基本信息 | 称呼、关系、生日、联系方式和紧急联系人。只有称呼必填 | 本人可改个人资料。管理员可维护家庭名册，为未绑定账号的成员指定资料维护人 |
| 健康档案 | 有授权时显示过敏信息、紧急联系人和按日期倒序的个人记录。时间线可按就诊、体检、疫苗、测量筛选 | 点击记录查看摘要与附件，可按权限新增、更正和约复诊 |
| 共享与照护 | 本人或有权管理照护的成员可查看「谁可以看、谁可以维护」。管理家庭的入口单列账号邀请、财务权限及成员状态 | 可选择具体成员授权、调整权限或撤回。确认前列明影响的档案和提醒 |

基础名册对家庭可见。家庭公共资料包括称呼、头像和关系。生日、联系方式和紧急联系人由本人或资料维护人选择是否在家庭资料中展示。健康页引用的应急信息沿用档案授权。未获健康权限时不展示任何记录数量、病史摘要或附件预览。

## 建档与账号生命周期

1. **加入家庭。** 管理员在名册选「邀请新成员」，或在已有档案上选「邀请本人绑定」。接受邀请时显示所属家庭和目标称呼，确认后沿用该成员的原有记录。绑定邀请仅对发起时选中的档案生效，已绑定的档案显示当前账号状态。涉及代建健康档案的交接按下述照护确认办理。
2. **为家人代建。** 选择「暂不绑定账号」，填称呼即可保存基本资料。第一次为该成员开健康档案时明确指定负责照护的家庭成员，再录入健康内容。有账号成员负责授权自己的档案。接管代建档案时，由原照护人与接管者确认身份和现有共享名单。
3. **退出或停用。** 停用前列出未完成的家庭任务、认领的待购项和本人负责照护的档案。公共任务可移交或改为待分配。若是无账号成员唯一的照护人，应移交给合适的照护人，或先封存该档案。停用后立即终止访问，历史记录保留经手人称呼。

## 健康记录与复诊

从成员资料点「新增健康记录」，面板顶部固定显示「为谁记录」。先选类型和日期，再按需要补充内容。报告附件归属于具体记录，可在详情预览或打开。修改时保留修改人和时间。

| 类型 | 快速填写 | 可选补充 |
| --- | --- | --- |
| 就诊、体检 | 日期、摘要，如「年度体检」 | 机构、科室、记录内容、报告附件、下次复诊日期 |
| 疫苗 | 日期、疫苗名称 | 接种机构、剂次、后续预约日期 |
| 测量 | 日期、项目、数值、单位 | 时间、备注。同一项目按日期排列，数值始终连同单位展示 |

「约复诊」带入成员称呼和选定日期，由操作者确认时间与参与人。参与人只能从当前可见该档案的家庭成员中选择。保存后健康记录显示下一次复诊日期，点击可打开日程。从日程改期后这里反映最新日期。同一记录再次点击入口会先显示已有预约，避免误建两次。

## 权限边界

| 身份或授权 | 可以做什么 |
| --- | --- |
| 普通家庭成员 | 查看共享名册、参与家庭物资与采购，管理自己的资料、日程和健康档案 |
| 家庭管理员 | 维护家庭成员、账号邀请与财务授权。查看他人的健康档案也需要档案授权 |
| 财务查看／记账 | 查看授权可读的家庭账目。记账成员还可维护流水、资产和预算。采购人只留实付金额时由记账成员接续处理 |
| 健康查看／维护 | 仅对获授权的具体成员生效。查看可读记录和附件，维护可新增、更正、安排复诊。授权名单由本人或代建档案的负责照护人管理 |

复诊日程的实际可见人取日程共享名单与当前档案授权的交集。撤回权限立即作用于档案、附件、搜索、首页和未发送的提醒。成员用浏览器返回已打开的详情或沿旧链接进入时重新校验权限，页面只提示「当前无权查看」。调整财务权限只影响财务入口和相关数据。

## 桌面验收

| 操作 | 可核对的结果 |
| --- | --- |
| 建一个未绑定账号的孩子档案，指派照护人并上传体检报告 | 名册里有一位孩子，指定照护人可看报告，普通成员的名册中只出现允许共享的资料 |
| 照护人登记复诊，从周历改到下周 | 时间线链接打开新的日期，日历只显示一次复诊，其他成员看不到该事项 |
| 撤回照护人的权限，再从旧链接打开报告 | 搜索、首页、日历及附件均无法继续读取该记录，已排期但尚未发送的提醒同步撤回 |
| 成员认领了采购并留下历史流水，随后退出家庭 | 待购可以重新分配，旧流水经手人可识别，该账号无法再访问本家庭资料 |
