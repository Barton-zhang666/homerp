# 成员与健康档案详细设计

单机版使用同一份成员名册。账号由家庭成员自行注册，日程负责人、采购经手人和业务记录所有者均可引用成员 ID。成员改称呼后仍保留这份身份。

## 账号与基本资料

每位家人在注册页填写家庭称呼、邮箱、密码及确认密码。注册或登录成功后进入仪表盘，查看家庭成员人数和本月生日。「用户管理」提供共享名册，可按称呼或家庭关系搜索并查看成员资料。侧栏底部的账户菜单可进入「个人中心」，编辑本人的称呼、关系、生日、联系方式和紧急联系人，或修改密码。

成员名册按基本资料、联系信息和账号权限分组。成员可以补充备用电话及供家人联系的邮箱，旧资料的这两项默认为空。资料中的联系方式供家人共享，登录邮箱只在本人的账号设置中出现。更改密码需要验证当前密码，已登录设备的会话随即失效。实现步骤见[账号与成员](accounts.md)。

## 记录归属

所有成员权限一致。已登录成员可读取家庭共享内容，每条个人记录只能由所有者修改。所有者在服务端由当前会话确定。后续模块的编辑、更正、删除和附件变更均须执行同一检查，列表、搜索和详情使用相同的读取规则。

## 健康记录与复诊（后续切片）

本人在自己的成员资料中新增健康记录。面板固定显示成员称呼，先选类型和日期，再补充摘要与附件。记录按日期倒序，可以筛选类型。其他已登录成员可查看。更正保留修改人和时间。

| 类型 | 快速填写 | 可选补充 |
| --- | --- | --- |
| 就诊、体检 | 日期、摘要，如「年度体检」 | 机构、科室、报告附件、下次复诊日期 |
| 疫苗 | 日期、疫苗名称 | 接种机构、剂次、后续预约日期 |
| 测量 | 日期、项目、数值、单位 | 时间、备注，同一项目按日期排列 |

本人点击「约复诊」后，确认日期、时间与参与人。健康记录可打开关联日程，日程改期同步显示在时间线中。再次点击预约入口时应打开已有预约。

## 桌面验收

1. 两位家人分别注册并登录。每人都能查到另一位的称呼、关系和已填写的联系方式。
2. 编辑本人的资料后，另一位家人刷新即可看到结果。另一位只有阅读入口，服务端也限制写入对象。
3. 更改密码后，所有设备的旧会话失效。本人使用新密码登录后仍可访问原资料。
4. 后续健康切片验收同一条记录的本人更正、家人只读和关联日程改期。
