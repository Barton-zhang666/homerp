# homerp 家庭 ERP 系统设计

一家人打开 homerp，最常问的是「今天有什么事」「家里还有没有」「顺路要买什么」「这个月花了多少」。首页给出今天要处理的事，五个业务模块各自保存完整记录。同一件事可以一次办完，例如买回牛奶时，在采购清单确认数量和实付金额，食品库存与家庭账本就各有一条可追溯的记录。

## 首页与导航

手机首页从上到下排列三个区域。**今天**按时间显示自己的安排和全家事项，行内可完成或改期。**快捷操作**提供「记一笔」「加待购」「建日程」，没有记账权限的成员在第一格看到「登记入库」。**需要处理**仅在有内容时出现，按「即将到期」「库存不足」「待收货」合并显示数量，点开即进入已筛选的清单。当天没有安排时显示日期和「建日程」。

手机底栏设「首页、物资、日程、采购、更多」，「更多」内直接列出财务与成员，常用的记账仍可从首页进入。桌面侧栏平铺首页和五个模块。各模块记住上次选择的分页和筛选，从详情返回后保留列表位置。

| 入口 | 打开时看到什么 | 最常做的操作 |
| --- | --- | --- |
| 物资 | 物品、食品、药品三个独立分页，记住上次查看的一页 | 查余量和位置、用掉、补货 |
| 日程 | 从今天开始的议程，可切换月历或长期计划 | 建安排、改期、完成一次任务 |
| 采购 | 全家共享的待购清单，其次是待收货和购买记录 | 随手添加、勾选买到的条目、确认收货 |
| 财务 | 本月收入、支出、结余和最近流水 | 记一笔、查账户、看预算和消费去向 |
| 成员 | 成员称呼和头像，点开进入个人资料 | 维护联系方式、查看获授权的健康档案 |

列表页只突出一个新增入口。入库默认数量 1，记账默认今天，创建日程时沿用当前选中的日期。保质期、付款账户等会影响结果的信息，缺失时明确显示「待补」或「待记账」。首次使用只需建立家庭并填写自己的称呼，位置、账户和其他成员都能在首次用到时添加。

## 物资管理

三类物资共用家庭位置、数量变动记录和采购入口，分别提供搜索、筛选、详情及新增表单。添加时由当前分页确定类别。位置采用「厨房、冰箱、药箱」这样的家庭用语，可直接新增。物资详情先回答「还有多少、放在哪」，再展示最近变动和补货设置。

| 分类 | 快速登记 | 详情与常用动作 |
| --- | --- | --- |
| 物品 | 名称即可建立，数量默认 1 件，可填位置 | 耗材如纸巾可「用掉」和设补货线。耐用品如电钻可「移位置」「借出／归还」「报废」，借出时记借给谁 |
| 食品 | 名称、数量和单位，可填存放位置、到期日 | 按到期日列出每批余量，可标记开封、吃掉或丢弃。首页的临期项直接打开对应批次 |
| 药品 | 药名、规格、库存单位和数量，有包装时录入有效期 | 同名不同规格分开。按包装批次查看有效期、位置和余量，可登记取用、补货或清理过期批次 |

第一次整理家里时，可以直接在当前位置登记已有存量。之后发现数量对不上，在详情点「盘点」，填实数即可预览差额。入库、取用、报废和盘点都保留变动日期、数量和经手人，方便家人核对。

同一食品或同规格药品分次入库时保留各批的数量与日期。列表显示最早到期日，消耗时默认选择最早到期的可用批次，也可改选实际拿取的一批。过期批次保留实物余量并进入「待清理」，从可用量中扣除。日期待补的批次单列，取用时由成员确认。家庭可分别调整食品、药品提前几天进入临期提醒。

库存单位在建档时确定，整箱采购、按盒使用时，收货人确认折合多少盒。可用量等于或低于设定的补货线时出现「加待购」，已有待购项则显示剩余待买量。

## 日程与长期计划

新建日程先填「做什么、哪一天」，默认全天、自己负责。点开时间可改为定时或跨天，按需要加参与人、提醒和重复规则。单次安排、每周家务、每月缴费和每年生日使用同一入口。共享范围可选自己、指定成员或全家。议程支持「我的／全家可见安排」筛选，同一件多人参与的事显示一次。

- **一次安排**可完成、改期或取消。到期未完成的任务留在待办，普通约会在结束后归入历史。每个提醒可延后或关闭，打开后回到这次安排。
- **重复安排**支持按日、周、月、年或自定间隔，选填结束日期。每周二、四倒垃圾可以只调换本周二这一次。修改时提供「仅这次」「这次及以后」，保留过去的完成记录。按月指定 31 日时，短月使用月末，并在预览中显示下三次日期。
- **长期计划**用目标和可选截止日期建档，例如「春节前整理全屋」。把厨房、储藏室等拆成可勾选的步骤，只给近期要做的步骤排日期。排期后同一步出现在日程与计划详情，任一处完成都会更新进度。未排期步骤留在计划中。进度按已完成步骤数展示，无步骤时可手动完成目标，暂停后可继续。

日程只表达约定或行动。勾选「交物业费」后可点「记一笔」确认实付，勾选「去复诊」后可进入获授权的健康档案添加记录。到期提醒和完成勾选本身都不产生账目或健康记录。

## 采购管理

采购用一张全家共享的清单。站在冰箱前就能输入「牛奶 2 盒」，从食品详情点「加待购」还会带入名称、规格和单位。同一物资已有未买数量时，展示已有数量，由添加人确认新的总需求。家人可以标记「我来买」，其他人能看到谁在买。

| 场景 | 操作 | 保存后的结果 |
| --- | --- | --- |
| 超市买回家 | 勾选本次买到的条目，确认实购数量。在同一页选「同时入库」「记家庭支出」 | 已买部分移入购买记录，缺货部分留在清单。入库沿用最近位置，记账填写小票实付总额和付款账户 |
| 网购未到货 | 确认已买，选择「待收货」，可先登记实付 | 已买数量从待购中移出。到货时按实收数量入库，未到的继续待收。收货页可查看已有的付款记录 |
| 暂时只想勾清单 | 只确认已买，库存和支出处理可稍后选择 | 购买详情保留「登记收货」「补记支出」「关联已有支出」入口，各动作显示处理进度 |
| 买错或退款 | 在原购买记录选退货数量，实际收到退款后登记金额 | 已入库物资按实际退回量冲减原批次。退款到账时冲减对应类别的消费。原购买、退货和退款可互查 |

一次结账可含多件商品，默认记一笔总支出。需要区分食品与日用品预算时，可在同一笔里拆分类别，分项合计须等于实付。卖家取消发货时可取消剩余待收数量，已付款项可在原购买记录下跟进退款。两位成员同时勾选同一条时，后确认的人会看到最新剩余数量。重复点确认只保留一组结果。

## 财务管理

财务页设「流水、资产、预算、统计」。日常入口「记一笔」默认支出，输入金额、点选常用类别即可保存，日期和上次使用的可用账户已有默认值。第一次记账可选「家庭现金」或新建账户，并确认期初余额。收入、转账、退款在切换类型后显示各自需要的字段。

| 页面 | 家庭能看到和处理什么 | 计算口径 |
| --- | --- | --- |
| 流水 | 收入、支出、转账、退款，可按时间、类别、经手人或账户查明细，采购支出可回到购买记录 | 账目以实际发生日归属月份。账户间转账只改变两个账户余额 |
| 资产 | 现金、银行和支付账户余额，手工登记的房车等资产估值，以及贷款等未偿负债 | 家庭净资产为账户余额加其他资产最近估值，减未偿负债。估值带日期，期初余额和估值调整单独记录 |
| 预算 | 按月设家庭总预算，也可为食品、日用品等设分类额度并沿用上月设置 | 显示已用、剩余、超出金额。分类支出同时占用总预算和对应类别额度，两层分别展示 |
| 消费统计 | 看当月净支出、分类排行和逐月趋势，点某一金额即可查看构成它的流水 | 净支出为实际支出减当期到账退款，结余为收入减净支出。统计和预算按同一日期、分类口径汇总 |

例如本月买食品花 60 元，另从银行卡转 500 元到家庭现金，再收到本月到账的食品退款 10 元。食品预算已用 50 元，消费统计也显示 50 元。转账在两个账户各留一条关联变动。若退款次月到账，则冲减次月食品净支出。

还贷时可把本金与利息拆开。本金同步减少账户余额和负债，利息从账户支付并计入支出。耐用品可按需关联一张资产卡，例如电动车的估值由财务维护，停放位置由物资维护。只有登记了估值的资产卡才计入净资产。

## 成员与健康档案

成员以称呼建档，生日、关系、联系方式和紧急联系人均可补充。成员档案可独立于登录账号存在，方便为孩子或老人记录事项。家庭管理员负责邀请、绑定账号、停用成员及维护家庭设置。历史流水、采购与日程保留当时的成员归属。

健康档案按人组织。顶部放常用的过敏信息与应急联系人，时间线收纳就诊、体检、疫苗和带单位的测量记录。新增记录先选类型、日期并写摘要，可附报告或照片。需要后续行动时可从记录建复诊提醒，日程沿用同一可见范围。

家庭物资和购物清单默认共享。家庭管理员可指定记账成员。仅参与采购的人仍可记录实付金额，采购显示「待记账」，记账成员选择付款账户后才生成账目。共享购买记录只展示该次购买的信息，进入账户余额与其他流水需要财务权限。

健康档案默认由本人查看，可单独授予指定照护人查看或维护权限。没有账号的被照护成员在建档时指定一名照护人。管理员查看健康档案也需取得相同授权。撤回授权或成员退出时，首页、搜索、提醒、附件以及已关联日程都按当前权限收回访问。

## 模块如何协作

每条事实有一个负责模块。物资保存品目、批次与数量变动，采购保存需求、购买与收货记录，财务保存账目与余额，日程保存安排及计划步骤，成员保存身份、共享授权与健康记录。首页只汇总当前成员可见的内容。跨模块操作由应用层按来源记录关联结果，各模块通过标识和应用接口协作，符合既有分层。[后端 DDD 约定](backend-ddd.md)

以一次购买为例，「已购买、已入库、已记账」分别由购买数量、收货批次和付款流水决定。结账页在确认前列出本次将写入的数量、账户与金额。选择同时办理的动作一起保存，失败后保留输入供重试。分开办理时，每次只更新选中的事项。同一次收货或付款可在来源记录查到唯一结果。更正从原记录进入。批次中已有一部分被用掉时，可冲减的数量以该批现存量为限，差额提示核对。

## 设计验收场景

| 家人从哪里开始 | 可以据此验收的结果 |
| --- | --- |
| 在食品页找牛奶，两批各剩 1 盒，到期日不同 | 列表显示共 2 盒和最近日期。点「吃掉 1 盒」默认扣较早一批，另一批数量和日期保留 |
| 待买牛奶 3 盒，家人只买到 2 盒，共付 18 元 | 一次确认后待购剩 1 盒，库存增 2 盒，财务只有一笔 18 元支出。返回重试结果相同 |
| 已付 40 元网购两件纸巾，分两天到货 | 第一次收货后待收剩 1 件，第二次后清零。账户总扣款始终为 40 元 |
| 从首页将本周二的家务改到周三，再完成一项全屋整理步骤 | 本周四和下周的重复安排保持原日期。已完成步骤在计划详情与当天议程同步 |
| 想知道本月为什么超预算 | 从预算点食品类别可看到采购、手记支出和退款，明细合计等于该类已用额 |
| 家人为孩子保存体检报告并约复诊 | 指定照护人可查看报告和提醒，其他成员在家庭首页、日程及附件入口均看不到相关内容 |

首版优先打通上面六个场景，覆盖五个模块。条码录入、小票识别、银行账单导入等提效功能可在家庭实际使用后评估。首轮走查以手机操作为主，重点观察家人能否独立完成一次补货、一次改期，并从预算数字找到对应的消费。
