# homerp 家庭 ERP 桌面 Web 系统设计

单机版共用一份家庭名册。所有成员自行注册、身份平等，业务内容共享读取，由所有者修改。用户模块的当前实现和权限约定见[账号与成员](modules/accounts.md)。

家人在电脑前打开 homerp，应当能看到今天的安排、查到家里的东西、勾完一张购物小票，或弄清楚某类支出为何超预算。首页负责引导，左侧导航直接进入五个模块。日历、库存表和家庭账本各自使用适合该任务的版式。

## 模块入口与详细设计

| 侧栏入口 | 进入后的主视图 | 记录归属与设计文档 |
| --- | --- | --- |
| 物资 | 物品、食品、药品，记住上次打开的一类 | 品目、位置、库存批次与数量变动。[物资详细设计](modules/inventory.md) |
| 日程 | 本周日历，可切换月历、议程或长期计划 | 日程、重复安排、提醒与计划步骤。[日程详细设计](modules/schedule.md) |
| 采购 | 全家待购清单，可多选条目一起结账 | 待购需求、购买、收货与退货记录。[采购详细设计](modules/procurement.md) |
| 财务 | 本月收支与流水表，可进入资产、预算和统计 | 账户、资产负债、流水与预算。[财务详细设计](modules/finance.md) |
| 成员 | 成员名册与当前选中的成员资料 | 成员身份、授权与个人健康档案。[成员详细设计](modules/members.md) |

## 桌面页面框架

以 1440 × 900 的浏览器窗口编排页面，用 1280 × 720 的笔记本窗口复核。左侧常驻「首页、物资、日程、采购、财务、成员」，各成员可进入相同模块。顶部展示家庭名称与当前登录成员。主工作区从上至下依次为页面标题和主操作、模块内导航、当页内容。页签、选中行与当前位置均有文字或形状标识。

首页采用两栏。左侧约占三分之二，按时间列「今天的安排」，显示时间、事项和负责人，可原位完成或改期。右侧先列「需要处理」，例如「3 批食品即将到期」「1 笔采购待收货」，点击数字直达对应筛选结果。下方提供「记一笔」「加待购」「建日程」。某栏无事项时用一句话说明，例如「今天没有安排」，保留相应的新建入口。

| 桌面交互 | 统一约定 |
| --- | --- |
| 查找与比较 | 搜索、常用筛选与清除筛选放在列表上方。数量和金额右对齐并显示单位，长表滚动时仍能辨认列名。主操作、名称和状态在笔记本宽度下保持可见 |
| 查看详情 | 点击名称或聚焦后按回车打开详情。核对单条记录用右侧面板，复杂的月历、计划、结账和预算使用完整工作区。返回时恢复日期、筛选、选中行和滚动位置 |
| 填写与保存 | 表单标签常驻，先列完成本次动作所需字段，备注、分类细项等按需展开。页内只突出当前任务的主按钮。保存后更新原行并给出具体结果 |
| 键盘与窗口 | Tab 可依次操作筛选、行链接和表单。Esc 关闭未修改的面板，焦点回到原入口。有未保存内容时可选择继续编辑。窗口变窄时，次要列移入详情，面板可覆盖工作区 |
| 空页与异常 | 区分「尚无记录」和「没有匹配结果」，分别给出新增、清除筛选入口。字段有错就近提示，保存失败保留输入。多人修改同一记录时展示最新差异，让成员确认后重试 |

## 家庭数据与跨模块操作

成员自行注册、填写称呼后即可使用。位置、付款账户可在首次用到时建立。已登录家人可查看业务记录，所有者负责维护自己的内容。首页汇总、列表数量、链接与附件都沿用来源记录的权限。退出登录后须重新登录才能访问，历史业务记录保留经手人。

| 从哪里发起 | 操作后分别留下什么 |
| --- | --- |
| 食品详情的「加待购」 | 采购记录待买数量，物资详情显示剩余待买量。买到、入库时才分别更新购买和库存 |
| 购物清单的「确认购买」 | 采购保存实购量。按实际情况勾选收货和记账，由物资保存入库批次、财务保存实付流水 |
| 健康记录的「约复诊」 | 日程记录日期和参与人，成员模块保存报告与就诊详情。日历和提醒按健康记录的有效授权展示 |
| 长期计划中的步骤排期 | 日历与计划引用同一步骤，任一处完成只算一次。缴费提醒完成后，由成员确认实付金额和账户才生成支出 |

一次确认中选定的采购、库存与记账动作共同成功，失败后保留输入。分次办理时，购买记录分别显示已收数量和记账进度。重复提交同一收货或付款只产生一组变动。详情可沿来源返回，各模块通过应用层协作。[后端分层约定](backend-ddd.md)

## 桌面走查场景

1. 在笔记本窗口从首页点临期食品，打开一批牛奶并登记吃掉 1 盒，返回后仍在原筛选位置。
2. 在待购表勾选三种商品，按小票一次核对数量和实付。缺货的留在清单，分批到货的显示待收，账本中可找到本次付款。
3. 在周历把本周二的一次家务移到周三，再从计划给一个步骤排期。前者保留下周安排，后者在本周只占一个事项。
4. 从食品预算的已用金额进入构成它的支出和退款，核对合计后返回同一个月份。
5. 本人登记报告并约复诊。其他成员可从名册读取记录，只有本人可更正内容。
