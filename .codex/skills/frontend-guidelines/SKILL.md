# 前端交互与表单

## 组件与导航

- 按[项目级 shadcn Skill](../shadcn/SKILL.md)查阅组件用法，从 `packages/ui` 组合现有控件。
- 物品管理、食品管理、药品管理放在「物资管理」侧栏子菜单。当前分类有选中状态，刷新、浏览器前进和后退后，地址、选中项和内容保持一致。手机上选中分类后收起导航。

## 记录弹窗

- 物资登记、编辑和库存操作共用居中 Dialog，遮罩模糊背景。长表单只滚动内容区，让标题和底部操作始终可见。
- 桌面并排的单行输入框、数字框、日期框和选择框等宽等高，列间距一致；标签换行时，同排控件的上下边缘仍然对齐。检查选择框的外层容器和实际控件。窄屏改为单列，说明、展开按钮和多行输入按内容安排。
- 每个可填写字段在标签旁明确写「必填」或「选填」，并将标签关联到控件。标识与实际校验使用同一条件，按当前操作、类别和选项更新。例如登记时到期日可以留空，核对具体到期日时必须填写。

## 分页列表与库存状态

- 用独立的「状态」列承载库存不足、临期、借出等标签。多状态先显示需要优先处理的一项和剩余数量，点按或用键盘展开即可读全。保留文字，颜色作为辅助。
- 同一列表共用行高和单元格内边距。名称、规格和位置分别限制行数，完整数据放入详情。手机保留数量、状态和行操作，次要信息可并入名称列；图标操作须有可访问名称。
- 概览数字若可点击，计数范围应与点击后的结果一致。搜索、筛选、翻页时保留工具栏位置和焦点；空结果提供直接清除条件的入口。

## 动效与验收

- 表单使用统一的字段样式。「必填」用强调色和粗体，「选填」用次要文字色和常规字重。检查浅色和深色主题下未聚焦的输入框、日期框和选择框，边框与周围背景的对比度至少为 3∶1；键盘聚焦时显示额外的焦点环。

- 弹窗开合、子菜单展开和分类切换采用短促、可中断的过渡。优先使用组件库动效及 CSS 透明度、位移；系统开启「减少动态效果」时取消非必要动画。
- 检查有无规格、长名称和多状态样例在桌面和手机上的实际行高。翻页可让新结果短暂淡入，逐字搜索时保持列表稳定。以 Tab、Enter、Esc 走通「行操作 → 弹窗 → 返回」，并检查浅色和深色主题下的选中态、状态标签与焦点。
- 修改上述交互后，在桌面与手机宽度实测。展开补充字段，比较同排控件边缘；分别尝试漏填必填项和留空选填项。用键盘打开、切换焦点并按 Esc 关闭，确认焦点返回入口，连续操作时也能立即响应。
