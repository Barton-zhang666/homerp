# 前端交互与表单

## 组件与导航

- 按[项目级 shadcn Skill](../shadcn/SKILL.md)查阅组件用法，从 `packages/ui` 组合现有控件。
- 物品管理、食物管理、药物管理放在「物资管理」侧栏子菜单。当前分类有选中状态，刷新、浏览器前进和后退后，地址、选中项和内容保持一致。手机上选中分类后收起导航。

## 记录弹窗

- 物资登记、编辑和库存操作共用居中 Dialog，遮罩模糊背景。长表单只滚动内容区，让标题和底部操作始终可见。
- 桌面并排的单行输入框、数字框、日期框和选择框等宽等高，列间距一致；标签换行时，同排控件的上下边缘仍然对齐。检查选择框的外层容器和实际控件。窄屏改为单列，说明、展开按钮和多行输入按内容安排。
- 每个可填写字段在标签旁明确写「必填」或「选填」，并将标签关联到控件。标识与实际校验使用同一条件，按当前操作、类别和选项更新。例如登记时到期日可以留空，核对具体到期日时必须填写。

## 动效与验收

- 弹窗开合、子菜单展开和分类切换采用短促、可中断的过渡。优先使用组件库动效及 CSS 透明度、位移；系统开启「减少动态效果」时取消非必要动画。
- 修改上述交互后，在桌面与手机宽度实测。展开补充字段，比较同排控件边缘；分别尝试漏填必填项和留空选填项。用键盘打开、切换焦点并按 Esc 关闭，确认焦点返回入口，连续操作时也能立即响应。
